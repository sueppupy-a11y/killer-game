# 살인자 게임 v6 — 마피아 능력전

친구 12명이 링크/게임 코드로 참가하는 모바일 중심 멀티플레이 마피아 게임입니다.
사람이 부족하면 빈자리를 규칙 기반 BOT으로 채울 수 있으며 BOT 난이도를 쉬움/보통/어려움으로 선택할 수 있습니다.

## 게임 흐름

역할 확인 → 밤 능력 사용 → 아침 결과 → 낮 토론 → 투표 → 탈락 결과 → 다음 밤

모든 단계는 서버 시간에 맞춰 자동 진행됩니다.

## 12인 역할

살인마 진영 3명
- 살인마: 밤 살해
- 스파이: 특수능력 보유 여부 조사
- 공범: 상대의 밤 능력 방해. 살인마 사망 시 살해 권한 승계

시민 진영 9명
- 경찰: 살인마 진영 여부 조사
- 의사: 한 명 보호
- 경호원: 한 명을 대신 지킴
- 탐정: 한 명의 밤 행동 대상 추적
- 초감각자: 한 명의 능력 사용 여부 감지
- 시장: 낮에 정체를 공개하면 투표 2표
- 시민 3명

살인마 사망 시 살해 권한은 공범 → 스파이 순으로 자동 승계됩니다.

## BOT

외부 AI/API가 필요하지 않습니다.
BOT은 공개 채팅, 공개 투표 결과, 본인에게만 주어진 조사 결과만 사용합니다.
다른 플레이어의 숨겨진 역할을 추리에 사용하지 않습니다.

- 쉬움: 단순 추리, 적은 발언, 실수 많음
- 보통: 발언/의심/역할 주장/투표 패턴 일부 기억
- 어려움: 모순, 역할 중복 주장, 투표 패턴, 개인 단서를 적극 활용

BOT은 밤 능력과 투표도 자동 수행합니다.

## Render 배포

`render.yaml`이 포함되어 있습니다.
GitHub 저장소에 파일을 덮어쓴 뒤 Commit하면 기존 Render 서비스에서 자동 재배포됩니다.

빌드: `npm install --include=dev && npm run build`
시작: `npm start`
헬스체크: `/api/health`

## 참고

Render 무료 인스턴스의 로컬 파일은 영구 DB가 아닙니다. 서비스 재시작/재생성 시 오래된 게임방 데이터가 사라질 수 있습니다. 한 번의 친구 게임 세션 용도로는 서버 메모리와 임시 파일 저장을 사용합니다.
