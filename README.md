# 살인자 게임 — 친구용 12인 멀티플레이 웹앱

한 명이 게임방을 만들고 초대 링크를 공유하면, 친구들이 각자 휴대폰 브라우저에서 같은 방에 접속해 플레이하는 구조입니다.

## 핵심 동작

- 한 URL에서 방 생성 / 참가
- 6자리 방 코드 및 `?code=XXXXXX` 초대 링크
- 최대 12명 실시간 동기화(1초 폴링)
- 각 플레이어의 역할/방 후보/단서는 본인에게만 전송
- 방 후보 2개를 랜덤 생성 후 1개 선택
- 모든 생존자가 방 선택을 확정하면 자동으로 낮(DAY) 단계 진행
- 새로고침/브라우저 재접속 시 같은 기기의 세션 복구
- 로비에서 나가면 실제 참가 슬롯 해제
- 서버 상태를 `.data/games.json`에 저장해 일반적인 단일 서버 재시작에 대비

## 로컬 실행

```bash
npm install
npm run dev
```

같은 와이파이에서 테스트할 경우, 서버를 실행한 컴퓨터의 LAN IP와 포트 3000으로 접속할 수 있습니다. 실제 친구들에게 인터넷 링크를 주려면 아래처럼 Node 서버를 배포해야 합니다.

## 배포

이 프로젝트는 프론트엔드와 Express API가 한 서버에서 같이 동작하므로 정적 호스팅(GitHub Pages)만으로는 멀티플레이가 되지 않습니다. Render, Railway, Fly.io처럼 Node 서버를 실행할 수 있는 호스팅에 전체 프로젝트를 배포하세요.

Render를 쓸 경우 저장소 루트의 `render.yaml`을 사용할 수 있습니다. 배포 후 생성된 주소가 예를 들어 `https://killer-game.example.com`이라면 방장이 로비의 **초대 링크 공유** 버튼을 눌렀을 때 `https://killer-game.example.com?code=ABC123` 형태로 친구에게 전달됩니다.

## 운영상 제한

현재 구조는 친구 12명이 한 방에서 즐기는 단일 서버용입니다. 여러 서버 인스턴스로 자동 확장하는 대규모 서비스로 운영하려면 게임 저장소를 Redis/Postgres 등 외부 DB로 교체해야 합니다.
