# 살인자 게임 v8 — 재대결 인원 선택

v7의 유령 역할 + 대화형 규칙 기반 BOT을 유지하면서, 한 판 종료 후 다음 판 인원을 다시 구성할 수 있게 개선한 버전입니다.

## v8 핵심 변경

- 게임 종료 후 HOST가 `BOT 유지하고 로비로` / `BOT 빼고 친구 기다리기` 중 선택
- BOT 유지 시에도 즉시 재시작하지 않고 로비에서 대기
- 가득 찬 로비에 새 친구가 참가하면 BOT 한 명을 자동으로 빼고 친구가 자리 승계
- 로비에서 언제든 `BOT 모두 빼기` 가능
- 사람이 부족하면 다시 `빈자리 BOT으로 채우기` 가능
- 12명이 새로 꽉 차면 기존 자동 시작 카운트다운 사용
- HOST는 언제든 `지금 시작` 가능

## 게임 흐름

역할 확인 → 밤 능력 → 아침 결과 → 낮 대화 → 투표 → 탈락 → 반복 → 게임 종료 → 다음 판 인원 선택
