# 살인자 게임 v11 — 질문할 때만 답하는 BOT

12인 링크 접속형 마피아 게임입니다. 사람 부족 시 규칙 기반 BOT이 빈자리를 채우며, 별도 AI API 연결 없이 작동합니다.

## v7 핵심 변경

- 👻 **유령 역할 추가**: 시민 진영. 탈락 후 낮 토론에서 익명 힌트를 최대 2번 남길 수 있습니다.
- 🤖 **BOT 응답형 대화**: BOT은 먼저 떠들지 않고 사람이 질문했을 때만 답합니다. 특정 BOT 이름을 부르면 그 BOT만 답합니다.
- ↪ **답글 표시**: BOT이 어떤 질문에 답했는지 채팅에 원문 미리보기가 표시됩니다.
- 질문 의도 인식: `누구 의심해?`, `왜 의심해?`, `나 의심해?`, `역할 뭐야?`, `어젯밤 뭐 했어?`, `누구 투표할 거야?`, `OO 어떻게 생각해?` 등에 맞춰 다른 답변을 생성합니다.
- BOT 이름을 채팅에서 누르면 입력창에 이름이 자동으로 들어갑니다. 질문이 아닌 일반 발언에는 BOT이 끼어들지 않습니다.
- BOT 난이도 쉬움/보통/어려움 유지.
- BOT은 자기 역할/자기 단서/공개 채팅/공개 결과만 이용하며 시민 BOT이 숨겨진 역할을 몰래 읽지 않습니다.

시민 진영 9명

## 흐름

역할 확인 → 밤 능력 → 아침 결과 → 낮 토론 → 투표 → 탈락 → 다음 밤

12명이 모이면 자동 시작합니다. 빈자리는 로비의 `빈자리 BOT으로 채우기`로 채울 수 있습니다.


## v11 추가
- 투표 단독 최다 득표자에게 20초 `최후의 발언` 단계 제공
- 최후의 발언 시간에는 지목된 플레이어만 채팅 가능
- BOT이 최다 득표자면 역할/추리 상황에 맞는 최후 발언을 자동으로 1회 남김
- 동률 투표는 최후의 발언 없이 기존처럼 아무도 탈락하지 않음
