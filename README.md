# 살인자 게임 — 친구용 12인 멀티플레이 웹앱

## 현재 라운드 진행 순서

1. 대화 — 60초
2. 방 선택 — 각 플레이어에게 랜덤 후보 2개가 주어지고 그중 1개 선택, 15초
3. 특수능력 선택 — 사용형 직업은 능력을 실행하거나 미사용, 15초
4. 낮/결과 발표 — 사망·체포 결과와 본인 전용 단서 확인, 8초
5. 자동으로 다음 라운드 시작
6. 다시 대화 -> 방 선택 -> 특수능력 -> 낮 결과 순환

모든 단계 전환은 서버에서 자동 처리됩니다. 방 선택 단계가 시작되면 화면은 자동으로 방 선택 UI로 이동하고, 방 선택이 끝나면 능력 화면으로 자동 이동합니다.

## 규칙 기반 BOT 플레이어

외부 AI/Gemini 연결 없이 서버 내부 규칙 엔진으로 동작합니다.

- 사람 수가 부족하면 `빈자리 BOT으로 채우기`로 12명까지 자동 보충
- BOT 난이도: 쉬움 / 보통 / 어려움
- 대화 시간에 BOT이 자연스럽게 1~4회 발언
- 공개 채팅에서 방 주장, 의심 발언, 주장 변경/모순을 추적
- 자기 직업의 비밀 단서만 활용하고 다른 사람의 숨겨진 역할은 추리 판단에 사용하지 않음
- 살인마 진영 BOT은 난이도에 따라 방 주장을 블러핑할 수 있음
- 법의학자/목격자/초감각자 BOT은 난이도에 따라 얻은 정보를 일부 공유
- 경찰, 교도관, 부패경찰, 도박꾼 BOT은 특수능력 단계에서 스스로 판단하여 능력 사용
- 감옥에 갇힌 BOT은 난이도에 따라 탈옥권 사용 여부 판단
- 사람이 새 채팅을 보내면 보통/어려움 BOT은 반응 시간을 앞당김
- BOT이 먼저 빈자리를 채웠더라도 자동 시작 전 실제 친구가 들어오면 BOT 자리 하나를 교체

### 난이도 차이

- **쉬움**: 말수가 적고 추리 실수가 많으며, 성급하거나 일관성이 떨어질 수 있음
- **보통**: 공개 발언의 모순을 추적하고 적당히 질문·의심·블러핑을 사용
- **어려움**: 여러 발언을 더 적극적으로 비교하고 역질문, 증거 공유, 의심 누적, 블러핑 빈도가 강화됨

## 멀티플레이

- 같은 Render 링크에서 방 생성
- 6자리 게임 코드 또는 `?code=XXXXXX` 초대 링크 공유
- 최대 12명
- 약 1초 간격 상태 동기화
- 실시간 공개 채팅
- 역할/방/비밀 단서는 본인에게만 노출
- 12명이 모이면 10초 후 자동 시작
