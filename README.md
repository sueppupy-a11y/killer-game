# 살인자 게임 — 친구용 12인 멀티플레이 웹앱

## 현재 라운드 진행 순서

1. 대화 — 60초
2. 방 선택 — 각 플레이어에게 랜덤 후보 2개가 주어지고 그중 1개 선택, 15초
3. 특수능력 선택 — 사용형 직업은 능력을 실행하거나 미사용, 15초
4. 낮/결과 발표 — 사망·체포 결과와 본인 전용 단서 확인, 8초
5. 자동으로 다음 라운드 시작
6. 다시 대화 -> 방 선택 -> 특수능력 -> 낮 결과 순환

모든 단계 전환은 서버에서 자동 처리됩니다. 방 선택 단계가 시작되면 화면은 자동으로 방 선택 UI로 이동하고, 방 선택이 끝나면 능력 탭으로 자동 이동합니다.

## 멀티플레이

- 같은 Render 링크에서 방 생성
- 6자리 게임 코드 또는 ?code=XXXXXX 초대 링크 공유
- 최대 12명
- 약 1초 간격 상태 동기화
- 실시간 공개 채팅
- 역할/방/비밀 단서는 본인에게만 노출

## 배포

Render Blueprint의 무료 Node Web Service용 `render.yaml`이 포함되어 있습니다.
